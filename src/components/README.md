# components

Shared UI pieces, one folder each, with a colocated `*.stories.tsx`.

- `PalettePreview/` — renders `src/styles/theme.ts` as light + dark panes (hero, section title, card, swatches with contrast ratios). Reference for the locked palette, not a site section.
- `TermSection/` — `TermSection`: a terminal window running `tree ~/jjenkins/<dir>` with CSS-drawn tree rails; runs like Home (command types, then the root line and each entry print top-down) once, when the deck has its slide fully in view (scroll settled on its step) or, without `active`, when it first scrolls into view; gutter line numbers on tree entries; a node row wraps, and on phones its meta drops under the name; renders `TermItem[]` (name/href, dim, badge, note, meta, line, hot — pink-chip number, children). Reused for Projects, Experience, Elsewhere. Story: `Sections/TermSection`.
- `TermSection/Window.tsx` — `Window`: shared mac-style terminal chrome (bar, lights, title) around a `tsec-body`; used by PageView and App's not-found page.
- `TermSection/useCat.ts` — `useCat(cmd, count, go)`: the shared run (type the command, then print `count` blocks with a random wait each; `go` holds it; skipped under `prefers-reduced-motion`). TermSection and PageView use it; Home keeps its own run with the ms stamps.
- `ProjectPage/PageView.tsx` — `PageView`: one terminal window running `cat README.md` — header (name, dates, lede, `Fact[]` label rows, optional link), then `PageSection[]` (h2; body splits on `\n\n` into paragraphs, media, optional `SubSection[]` rendered media-first when `mediaFirst`; a sub may carry its own `subs` with a `layout`, so one section splits into h3 parts that each hold a snake or work tree), `$ cd ..` back to `#<dir>`. Runs like Home: the command types, then each block (header, lede, facts, h2s, paragraphs, labelled blocks, media, subs — a snake or work tree prints as one) fades in top-down; skipped under `prefers-reduced-motion`. `SubSection.when` renders mono right of the h3; `PageSection.note` is a small mono line under the h2. Owns the Media/SubSection types and rendering below.
- `ProjectPage/ProjectPage.tsx` — `ProjectPage`: `ProjectPageData` → PageView (concepts/stack/remote rows; problem → features (media before body) → difficulties). Story: `Pages/Project`.
- `ProjectPage/ExperiencePage.tsx` — `ExperiencePage`: `ExperiencePageData` (org as name, role, dates, line, optional concepts, stack, optional site) → PageView; `sections` come from the data (context / work / lessons by convention, a page may add its own). Story: `Pages/Experience`.
- `ProjectPage/Snake.tsx` — `Snake`: a section with `layout: 'snake'` puts its subs on one winding path (rows of date + title dots, whole list visible, selected sub's detail below with prev/next; tapping the open dot closes it).
- `ProjectPage/WorkList.tsx` — `WorkList`: a section with `layout: 'work'` puts its subs on a tree (rails plus a numbered gutter; a row shows its `line` as an overview until opened, then the detail replaces it and the row scrolls its header to the top). Only the header is the control.
- Media kinds (PageView): `pre` (code/ascii; without `lang`, `{{x}}`/`[[x]]`/`((x))` = accent/green/amber spans; `tight` is for diagrams: it closes the line gaps and switches to one font that carries the box drawing glyphs itself, so the rules stay joined and in column), `anim` (looping ascii animation: `frames` cycled every `ms`, same span markers and the same `tight`; frames must share one fixed size), or `base` + `path` (one diagram with a green pulse of `run` cells sliding along the polyline `path`, row/col vertices counted on the rendered text, draining off the end before it loops), `img`, `chat` (example conversation: user bubbles, ai dot-rows with tool calls), `video` (row of muted looping phone screen recordings in device bezels from `public/demo/`, per-clip `cap`). A `PageSection` or `SubSection` may carry `blocks` (`Block[]`) instead of one flat `body`: each block is a mono accent `label`, prose, and its own `media`, so a diagram sits with the paragraph it explains rather than at the bottom (`mediaFirst` puts it above the prose; `label` is optional). A snake sub may carry `photos` (`Photo[]`, files in `public/<slug>/`): one sits beside the prose, two share a row at equal height, each sized from its own `w`/`h`; `phone` frames a screenshot in a device bezel. Prose (lede + bodies): `` `x` `` = inline-code chip, `[text](href)` = link.
